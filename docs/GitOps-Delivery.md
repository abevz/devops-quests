# Восстановление приватного реестра и GitOps

Используйте только одноразовую песочницу задания. Kubelet загружает приватный образ с помощью Secret из того же пространства имён, указанного в `imagePullSecrets`. Digest определяет неизменяемое содержимое образа; `imagePullPolicy: Always` вызывает проверку загрузки при запуске. Изучите `platform.env`, `private-release.json`, `board.json` и `registry-pull.json`, если они выданы. Берегите игровые учётные данные: не выводите их и не сохраняйте в истории терминала. Проверьте события Pod и дождитесь `kubectl rollout status deployment/board --timeout=90s`; успешный текущий rollout не доказывает будущие загрузки.

Application Argo CD выбирает репозиторий, путь, ревизию и назначение. Контроллер согласует состояние асинхронно: `Synced` описывает сравнение с Git, а `Healthy` — состояние ресурсов. В app-of-apps родитель согласует дочернюю Application, которая согласует нагрузку. Сравните оба объекта с отправленным коммитом и сохраните идентичность родителя. `wait-apps.sh` в песочнице проверяет ожидаемые Application; повторите после согласования, а не предполагайте мгновенный результат.

Генератор списка ApplicationSet передаёт параметры шаблону Go; путь вида `stations/{{.station}}` создаёт путь для каждого элемента. В задании ApplicationSet игровой опрос отправляет один из двух ограниченных манифестов из `applicationset.json` приватному контроллеру. Это адаптер с ограниченным набором изменений, а не общий API контроллера. Дождитесь созданных Application и проверьте владельца, ревизию, состояние и фактические ответы нагрузки.

Источники: [загрузка приватных образов](https://kubernetes.io/docs/tasks/configure-pod-container/pull-image-private-registry/), [генератор списка Argo CD](https://argo-cd.readthedocs.io/en/stable/operator-manual/applicationset/Generators-List/), [шаблоны Go](https://argo-cd.readthedocs.io/en/stable/operator-manual/applicationset/GoTemplate/).
