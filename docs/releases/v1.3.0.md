v1.3.0 makes quest instructions, check feedback and guides clearer across the 130-quest curriculum.

- Hints show consecutive repeated guide links only once (dq-3).
- Early quests explain the supplied files, expected results and recovery goals more clearly, with stronger checks for state and file-content recovery (dq-6, dq-7, dq-8 and dq-9).
- Failed checks explain individual conditions in English, Polish, Spanish, German and Russian. Intermediate and advanced briefs and topic guides now give more useful context (dq-10 and dq-11).
- Recovery checks for quests 081, 090 and 098 distinguish file contents from permissions correctly; quest 080 handles its disposable registry credentials more carefully (dq-11).
- Linked guides now explain the same quest example across Basics, Medium and Advanced, including the cross-system Boss incidents, in all five languages (dq-13).
- Authoring rules now require accurate quest examples and guidance that suits each difficulty. Maintainers preview merged changes locally and release them as a separate owner-authorized task (dq-12 and dq-4).

The signed-in username display introduced in v1.2.2 remains available in navigation and Profile / Settings (dq-1).

No database schema migration is included. Accounts, progress, pending briefing hints and saved Lab files are preserved. Deployments refuse active attempts, pending briefing hints and active or incompatible saved Labs. The previous release remains available for rollback through the documented operator procedure. Sandbox image inputs and third-party dependency pins are unchanged.
