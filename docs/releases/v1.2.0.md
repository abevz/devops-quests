v1.2.0 adds Polish, Spanish and German interface and content translations alongside English and Russian. All three are machine translations and are labelled as such in the language selector, the footer and translated guide content; English remains the reference text.

Translations cover the interface, quest briefs, guide topics and lessons. Validation now enforces key coverage for every language and keeps code blocks and technical literals identical to the source, so a translation cannot silently drop a command.

No database schema, sandbox image or dependency checksum changed. Existing prepared releases remain available for rollback under the normal progress, Lab and pending-hint gates.
