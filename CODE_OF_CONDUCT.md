# Code of conduct

Treat people respectfully. Welcome learners, explain technical disagreement with evidence,
and avoid harassment, discrimination, threats, doxxing and unwanted contact. Keep reviews
focused on behavior and code, and respect privacy and project boundaries.

Maintainers may edit/remove harmful content or restrict participation. Report ordinary
conduct concerns through a repository issue without personal data; for sensitive incidents
ask for a private channel without publishing the details. Security vulnerabilities go through
[private security reporting](SECURITY.md). Enforcement is contextual; no response SLA is promised.
